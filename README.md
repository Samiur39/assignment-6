# FitLog

FitLog is a workout management web application where users can browse workouts, view workout details, create a daily workout plan, save workouts for later, and track completed workouts.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide React
- React Hot Toast
- REST API

## Features

- Browse different workouts from the workout library.
- View detailed information and instructions for each workout.
- Add workouts to Today's Plan with a maximum of 5 workouts.
- Save workouts for later.
- Mark workouts as completed.
- Remove workouts from the plan or saved list.
- Sort workouts by duration, calories, and rating.
- Responsive design for mobile, tablet, and desktop.
- Toast notifications for different workout actions.
